# Wallpaper Picker

Browse Wallhaven or wallpapers in `~/Wallpapers`, preview them in a Quickshell picker, and apply one as an Omarchy theme. Wallust builds a matching palette from the image.

## Install

Install Wallust:

```bash
yay -S wallust-bin
```

Then install the plugin:

```bash
omarchy plugin add https://github.com/abhijeet-swami/omarchy-wallpaper-picker.git --enable
```

Open it from a terminal:

```bash
omarchy-shell shell summon abhijeet.wallpaper-picker '{}'
```

Or add a binding to `~/.config/hypr/bindings.lua`:

```lua
o.bind("SUPER + ALT + W", "Wallpaper Picker", "omarchy-shell shell summon abhijeet.wallpaper-picker \"{}\"")
```

## Controls

| Key | Action |
| --- | --- |
| Left / Right | Select a wallpaper |
| Mouse wheel | Scroll Wallhaven results |
| Click a thumbnail | Select it |
| Enter | Apply the selected wallpaper |
| Alt+1 / Alt+2 | Local wallpapers / Wallhaven |
| Alt+S | Search |
| Alt+D | Download the selected image to `~/Wallpapers` |
| Alt+Left / Alt+Right | Change Wallhaven page |
| Alt+P | Jump to a page number |
| Alt+M | Change sort order |
| Ctrl+S | Open appearance settings |
| Enter / Return in settings | Apply settings |
| Esc | Close the picker |

Wallhaven loads more results as you scroll, and stops at the first and last result. Search starts with relevance; Alt+M switches between relevance and top results. With an empty search, Alt+M cycles through top month, year, week, and recent.

## Features

- Local mode opens by default and searches wallpaper filenames.
- Wallhaven search, sorting, page jumping, and infinite scroll.
- Wallhaven thumbnails are cached for the session; local thumbnails stay in `~/.cache` and update when files in `~/Wallpapers` change.
- Apply a wallpaper as an Omarchy theme with colors generated by Wallust.
- Ctrl+S settings for blur, rounding, shadows, opacity, border width, and animation presets.
- Active and inactive window borders use colors from the generated Wallust palette. Border width also controls the picker dock, search field, and wallpaper cards.
- Wallust colors and adjustable background opacity for Kitty, Foot, and Ghostty, generated as part of the active theme.

The picker's dock position and blur can be adjusted in `~/.config/omarchy/plugins/abhijeet.wallpaper-picker/ui-config.json`:

```json
{
  "bottomOffset": 0,
  "backgroundBlur": false
}
```
